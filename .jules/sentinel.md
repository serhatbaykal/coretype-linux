## 2024-05-15 - [CRITICAL] Prevent TOCTOU in file/dir creation
**Vulnerability:** The app was using `std::fs::create_dir_all` and `std::fs::write` to create a directory and file to store secrets, then calling `std::fs::set_permissions` to change the file to `0o600` permissions. This creates a Time-of-Check to Time-of-Use (TOCTOU) vulnerability where an attacker with local access could potentially read the file's contents between the time it is written and the time the permissions are updated.
**Learning:** To prevent this, permissions must be set atomically during file/directory creation.
**Prevention:** Use `std::fs::DirBuilder` with `std::os::unix::fs::DirBuilderExt`'s `mode()` to set directory permissions at creation time (e.g., `0o700`). Use `std::fs::OpenOptions` with `std::os::unix::fs::OpenOptionsExt`'s `mode()` to set file permissions at creation time (e.g., `0o600`), then use `std::io::Write::write_all` on the created file descriptor instead of `std::fs::write`.
