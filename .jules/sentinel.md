## 2024-10-24 - [CRITICAL] Prevent TOCTOU vulnerabilities in file operations
**Vulnerability:** A Time-of-Check to Time-of-Use (TOCTOU) race condition was discovered in `save_secret` and `secrets_path`. These functions created a directory/file and later updated the permissions (`set_permissions` for the file) or relied on default permissions during creation before manually setting them. This left a small window where an attacker could access the file before it was secured.
**Learning:** File creation and permission configuration must be atomic. Separating the two actions creates a race condition that could be exploited to steal sensitive data (like secrets) before the restricted permissions take effect.
**Prevention:** Use `std::fs::OpenOptions` combined with `std::os::unix::fs::OpenOptionsExt` (`mode(0o600)`) for atomic file creation. For directory creation, use `std::fs::DirBuilder` with `.mode(0o700)`. This guarantees that files and directories are inherently created with the correct security permissions.
