## 2025-03-09 - [HIGH] Fix TOCTOU vulnerability in secret storage
**Vulnerability:** A Time-of-Check to Time-of-Use (TOCTOU) race condition existed in the secret storage mechanism. `save_secret` used `std::fs::write` followed by `set_permissions` to create `secrets.json`, and `secrets_path` used `create_dir_all`. Both of these approaches are vulnerable to a race condition where the file or directory can be created with overly permissive default settings, then opened by an attacker before the permissions are tightened.
**Learning:** Security-sensitive files and directories must be created with the correct permissions from the moment they are created to avoid giving an attacker a window of opportunity to read or tamper with them.
**Prevention:** In Rust, use `std::fs::OpenOptions` and `std::os::unix::fs::OpenOptionsExt` (`mode`) to atomically set permissions during file creation. For directories, use `std::fs::DirBuilder` with `std::os::unix::fs::DirBuilderExt` (`mode`) to securely create them.
