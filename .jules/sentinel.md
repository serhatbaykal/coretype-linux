## 2024-05-15 - Fix TOCTOU Vulnerability in Secrets File Creation
**Vulnerability:** A Time-of-Check to Time-of-Use (TOCTOU) vulnerability was found in the creation of the secrets configuration directory and the secrets file (`secrets.json`). The directory and file were created with default permissions (potentially world-readable) and then later locked down using `std::fs::set_permissions`.
**Learning:** Between the time the file/directory was created and when its permissions were updated, an attacker could potentially access or monitor the sensitive secrets. Using `std::fs::write` or `std::fs::create_dir_all` followed by `set_permissions` is non-atomic and inherently insecure for sensitive files on Unix systems.
**Prevention:** Always use `std::fs::OpenOptions` with `std::os::unix::fs::OpenOptionsExt` (`mode`) to atomically set permissions when creating files. Similarly, use `std::fs::DirBuilder` with `std::os::unix::fs::DirBuilderExt` (`mode`) to atomically set permissions when creating directories that store sensitive information.
